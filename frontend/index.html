    Why Non-Autoregressive Decision Models?

    Traditional generative LLMs (like GPT-4 or Claude) generate tokens sequentially, which introduces:

    • High Latency & Token Costs: Generating 500 tokens of JSON takes 2–4 seconds and consumes costly cloud API credits.
    • Schema Drift & Hallucination: Output can break, hallucinate non-existent JSON keys, or invent invalid category labels.
    • Uncalibrated Confidence: Generative models struggle to provide trustworthy probability distributions over operational policies.

    Laya passes state and questions through a bidirectional ModernBERT encoder, outputting structured probability distributions directly across pre-bounded answer heads in a single forward pass.

    The 3 Decision Primitives

    CHOICE
    Categorical Selection: Selects from a fixed set of named options with concrete criteria. Used for queue and solver routing.
    SCORE
    Ordinal Rubric: Rates inputs along an ordered scale (e.g. routine → elevated → blocking). Returns expected value and distribution.
    NOUL
    Proposition Probability: Evaluates the probability P(true) of a stated binary hypothesis. Used for safety and risk checks.

    REST API Quick Reference

    POST /api/triage

    Performs rapid Laya decision pass returning domain, difficulty, urgency, and abstention recommendations.

    POST /api/solve

    Executes full end-to-end pipeline: Triage → Route → Domain Solver → Laya Solution Verification.

    POST /api/eval

    Runs batch evaluation suite over held-out datasets to measure accuracy, calibration ECE, and latency.
